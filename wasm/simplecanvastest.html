HashLink WASM Canvas 2D Demo

Haxe → HashLink HL-C → Emscripten → WebAssembly

Demo Features:

  • Bouncing Ball - Red ball with gradient effect and physics
  • Rotating Circles - 8 rainbow-colored circles orbiting the center
  • Animated Grid - Background grid pattern
  • Pulsing Border - Animated border with sine wave effect
  • Text Overlay - Frame counter and ball position display
  • 60 FPS - Smooth animation using haxe.Timer
